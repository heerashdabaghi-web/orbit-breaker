# Orbit Breaker

A responsive browser survival game built with Canvas 2D, CSS, and vanilla JavaScript.

## Play locally

Start the development server (no installation required):

```bash
node scripts/dev.mjs
```

Open the local address shown in the terminal.

## Controls

- Move with `WASD`, arrow keys, or drag inside the arena.
- Release a charged pulse with `Space` or the Pulse button.
- Pause or resume with `P`, `Escape`, or the Pause button.
- Toggle sound with the Sound button.

Collect four green cores to charge a pulse. Avoid pink shards and survive as long as possible. Your best score is saved on the current device.
