# Content Skill

Use this guide for game text, naming, tutorials, story fragments, UI labels, and asset planning.

## Voice

- Use short, active, concrete language.
- Match the tone to the game world without obscuring instructions.
- Prefer familiar verbs such as Start, Continue, Pause, Retry, and Mute.
- Keep critical instructions on screen until the player has had time to use them.

## Essential Copy

Prepare concise text for:

- Game title and one-line hook
- Objective
- Controls
- Start button
- Pause and resume
- Score, time, health, or progress labels
- Victory and game-over messages
- Restart button
- Audio and accessibility controls

## Tutorial Pattern

1. Explain only the first required action.
2. Let the player perform it.
3. Introduce the next rule at the moment it becomes relevant.
4. Use visual examples where possible.
5. Do not interrupt active play with long paragraphs.

## Asset Guidelines

- Keep an inventory of every image, font, and sound with its source and license.
- Prefer original assets, procedural graphics, or clearly licensed public-domain/CC0 media.
- Use consistent dimensions, line weight, palette, and export settings.
- Compress assets without harming important visual details.
- Add meaningful alternative text to non-decorative interface images.

## Content Checklist

- Labels use the same term for the same concept everywhere.
- Instructions match the implemented controls exactly.
- End-state text tells the player what happened and what to do next.
- No placeholder text remains in the shipped interface.
- Text still fits at the smallest supported viewport and with browser zoom.
